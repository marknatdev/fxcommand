# Holdout is fixed at 2025-01-01 onward and never moves

The Research Window is 2014-01-01 to 2024-12-31. GOLD's intraday history on XM only begins in 2014, and every symbol shares one common window so that Verdicts compare across symbols. Everything from 2025-01-01 onward is the Holdout. The AI never sees it, and each Idea Family may spend it at most once. The boundary is fixed for good. A rolling or re-drawn holdout would let repeated looks leak into research, which is exactly the self-deception this product exists to prevent. As the Holdout grows stale, the Forward Arena (Layer B) supplies fresh evidence instead of a new split.

Only the owner can spend the Holdout, by approving a Holdout Request in the web app. The Research Desk and the MCP server can only request a spend, which keeps the one-time look deliberate.
