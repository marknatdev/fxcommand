# One vectorised signal function per Strategy, shared by live trading and backtests

Each Strategy computes its signals for every bar of a series at once (`signals(bars, params)`); live evaluation reads the last row, Backtests and Shadow Trades read every row. This keeps live behaviour and learning behaviour the same code path. Recursive indicators (EMA, Wilder smoothing) depend on where a series starts, so live evaluation is fed the Strategy's lookback plus 300 warm-up bars; a test asserts the live last row equals the full-series row on every sampled bar, and a golden fixture pins the pre-vectorisation behaviour. It also makes a 5,000-bar Walk-forward Backtest cost milliseconds, so an Optimizer Run can afford hundreds of Candidates. The price is that each Strategy must be written as column arithmetic rather than "look at the last bar", and exit rules that depend on the open position are expressed as separate long-exit / short-exit columns.
